# Price Checking Bot (v2.0 – Update) 📈
A Python-based web scraper that automates product price monitoring. It extracts HTML data using Requests and BeautifulSoup4, cleans currency formats into float numbers, and checks them against a user-defined budget. Runs in a continuous loop with built-in time delays to efficiently track price drops.

What's new in v2.0:
• 🛠️ Fault tolerance: Network error handling (try-except) & timeout.
• 🛡️ Anti-blocking: Added custom User-Agent.
• 🎯 Data safety: Full price input validation.
